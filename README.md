# 🧮 Advanced Scientific Calculator

A stunning, feature-rich scientific calculator with modern glassmorphism design and advanced functionality.

## ✨ Features

### 🎨 **Modern Design**
- **Glassmorphism UI** - Beautiful frosted glass effect with backdrop blur
- **Animated Gradients** - Dynamic background with moving patterns
- **Smooth Animations** - Ripple effects, hover animations, and transitions
- **Responsive Design** - Works perfectly on desktop, tablet, and mobile devices
- **Color-Coded Buttons** - Different colors for numbers, operators, and functions

### 🔢 **Basic Operations**
- Addition, Subtraction, Multiplication, Division
- Percentage calculations
- Decimal point operations
- Parentheses for complex expressions

### 🔬 **Scientific Functions**
- **Trigonometric**: sin, cos, tan (with deg/rad mode)
- **Logarithmic**: log (base 10), ln (natural log)
- **Exponential**: e^x, x^y
- **Roots**: Square root (√)
- **Powers**: x², x³, x^y
- **Other**: Factorial (!), Absolute value (|x|), 1/x

### 💾 **Memory Functions**
- **MC** - Memory Clear
- **MR** - Memory Recall
- **MS** - Memory Store
- **M+** - Add to Memory
- **M-** - Subtract from Memory
- **ANS** - Use last result

### 📊 **History Management**
- Automatic calculation history tracking
- View last 10 calculations
- Clear history option
- Persistent storage using localStorage
- Shows previous expression above display

### ⌨️ **Keyboard Support**
- **Numbers**: 0-9
- **Operators**: +, -, *, /, %, ^
- **Parentheses**: (, )
- **Decimal**: .
- **Enter** or **=** - Calculate
- **Backspace** - Delete last character
- **Escape** - Clear display
- **Delete** - Clear all

### 🎯 **Advanced Features**
- **Angle Mode Toggle** - Switch between degrees and radians
- **Error Handling** - Visual feedback for invalid expressions
- **Notification System** - Toast notifications for actions
- **Persistent Memory** - Memory saved across sessions
- **Result Animation** - Smooth typewriter effect for results
- **Visual Feedback** - Success/error flashes on calculation
- **Tooltips** - Helpful hints on button hover

### 📱 **Responsive Features**
- Adapts to all screen sizes
- Touch-optimized for mobile devices
- Optimized button layouts for small screens
- Accessible on any device

## 🚀 Usage

### Basic Calculations
1. Click number buttons or type on keyboard
2. Use operators (+, -, ×, ÷)
3. Press **=** or **Enter** to calculate

### Scientific Functions
1. Click function buttons (sin, cos, log, etc.)
2. Enter the value or expression
3. Close parentheses if needed
4. Press **=** to calculate

### Memory Operations
1. Calculate a value
2. Press **MS** to store in memory
3. Use **MR** to recall stored value
4. Use **M+** or **M-** to add/subtract from memory
5. Press **MC** to clear memory

### Angle Mode
- Click **DEG/RAD** button to toggle
- DEG mode: Trigonometric functions use degrees
- RAD mode: Trigonometric functions use radians

### History
- Click **History** button to view past calculations
- Click **Clear** to erase history
- History is automatically saved

## 📝 Mathematical Notation

- `sin(x)` - Sine (angle in deg/rad)
- `cos(x)` - Cosine (angle in deg/rad)
- `tan(x)` - Tangent (angle in deg/rad)
- `log(x)` - Logarithm base 10
- `ln(x)` - Natural logarithm (base e)
- `sqrt(x)` - Square root
- `x^y` - x to the power of y
- `n!` - Factorial of n
- `|x|` - Absolute value
- `1/x` - Reciprocal
- `π` - Pi (3.14159...)
- `e` - Euler's number (2.71828...)

## 🎯 Tips & Tricks

1. **Quick Clear**: Press `Escape` to clear the display
2. **Keyboard Shortcuts**: Use your keyboard for faster input
3. **Memory Chain**: Use M+/M- to accumulate multiple calculations
4. **ANS Button**: Quickly reuse the last result in new calculations
5. **History**: Review your calculation history anytime
6. **Angle Mode**: Remember to check DEG/RAD before trig calculations
