User Guide & Help

×

Basic Calculator

  • Numbers & Operations: Click number buttons or type directly
  • Operators: +, −, ×, ÷ for basic arithmetic
  • Percentage (%): Calculate percentages (e.g., 50% = 0.5, 200*15% = 30)
  • Clear (C): Clear current input
  • All Clear (AC): Clear everything including memory
  • Delete (⌫): Remove last character
  • Equals (=): Calculate result

Advanced Functions

  • x²: Square a number
  • √: Square root
  • xʸ: Raise to any power
  • sin, cos, tan: Trigonometric functions (check DEG/RAD mode)
  • ln, log: Natural and base-10 logarithm
  • π, e: Mathematical constants
  • ( ): Use parentheses for complex expressions

Memory Functions

  • MC: Memory Clear - Clear stored memory
  • MR: Memory Recall - Recall stored value
  • M+: Memory Add - Add current value to memory
  • M-: Memory Subtract - Subtract current value from memory
  • MS: Memory Store - Store current value

Advanced Features

  • Unit Converter: Convert between Length, Weight, Temperature, Volume, Speed, Area, Time, Currency, Data Storage
  • Equation Solver: Solve linear and quadratic equations
  • Graphing Calculator: Plot mathematical functions (supports implicit multiplication like 2x, 3sin(x))
  • Matrix Calculator: Perform matrix operations (Add, Subtract, Multiply, Determinant, Inverse, Rank) with flexible 2×2 to 5×5 sizing
  • Statistics: Calculate Mean, Median, Mode, Standard Deviation, Variance

Finance & Business Tools

  • Discount Calculator: Calculate final price after discount and savings
  • GST Calculator: Add or remove GST with rates (5%, 12%, 18%, 28%)
  • EMI Calculator: Calculate loan EMI with interest and tenure
  • Currency Converter: Convert between 50 world currencies

Health & Utilities

  • BMI Calculator: Calculate Body Mass Index with age and gender factors, visual scale with categories
  • Date Calculator: Calculate difference, add, or subtract days between dates

Keyboard Shortcuts

  • 0-9: Number input
  • + - * /: Basic operators
  • Enter: Calculate result (=)
  • Escape: Clear display (C)
  • Backspace: Delete last character
  • ( ): Parentheses
  • . : Decimal point

Themes

  • Click Theme button to choose from multiple color themes
  • Themes include: Classic, Midnight, Ocean, Forest, Sunset, Rose, Lavender, and Cyberpunk
  • Theme preference is automatically saved

History

  • All calculations are automatically saved in history
  • Click History to view past calculations
  • Click any history item to reuse it
  • Clear history when needed

Tips

  • Switch between DEG and RAD for trigonometric functions
  • Use parentheses for complex expressions: (2+3)*(4+5)
  • Graphing calculator supports implicit multiplication: 2x means 2*x
  • Matrix size can be changed dynamically from 2×2 to 5×5
  • Currency rates are approximate and updated periodically
  • BMI calculator shows visual scale with health categories

Need more help? Hover over any button to see tooltips!
